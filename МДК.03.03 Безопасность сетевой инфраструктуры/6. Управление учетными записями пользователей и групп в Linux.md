## Введение

Управление учетными записями пользователей и групп — одна из базовых задач системного администрирования. В Linux для этого используется набор стандартных утилит (`useradd`, `usermod`, `userdel`, `groupadd`, `passwd`, `chage`), которые работают напрямую с конфигурационными файлами системы.

**Пользователь (user)** — это учетная запись, которая идентифицирует человека, процесс или сервис в системе. Каждый пользователь имеет:

- **UID (User ID)** — числовой идентификатор (например, `1000`)
- **Имя пользователя** — текстовое представление (например, `john`)
- **Домашнюю директорию** — личное пространство для файлов (`/home/john`)
- **Оболочку (shell)** — программу, которая выполняется при входе (`/bin/bash`)

**Группа (group)** — это набор пользователей для упрощения управления правами доступа. Каждая группа имеет:

- **GID (Group ID)** — числовой идентификатор
- **Имя группы** — текстовое представление

**Типы пользователей:**

- **Обычные пользователи** (UID 1000+) — люди, которые работают с системой
- **Системные пользователи** (UID 1-999) — сервисы и приложения (например, `nginx`, `mysql`)
- **root** (UID 0) — суперпользователь с полным доступом

## Создание пользователей:

### Что происходит при создании пользователя

Когда вы создаете пользователя, система выполняет несколько действий:

1. **Добавляет запись в `/etc/passwd`** — основной файл с информацией о пользователях
2. **Создает запись в `/etc/shadow`** — файл с хешами паролей (доступен только root)
3. **Создается группа название которой соответствует имени пользователя** — добавляет запись в `/etc/group`
4. **Создает домашнюю директорию** (если указан флаг `-m`) — копирует содержимое из `/etc/skel`
5. **Устанавливает права доступа** на домашнюю директорию

`useradd` — это низкоуровневая утилита, которая создает пользователя без лишних вопросов.

```bash
# Создание пользователя с настройками по умолчанию
useradd john

# Создание пользователя с домашней директорией и bash-оболочкой
useradd -m -s /bin/bash john

# Создание системного пользователя (без домашней директории, UID из диапазона 100-999)
useradd -r -s /sbin/nologin app-service

# Полное указание всех параметров
useradd -m -s /bin/bash -c "John Smith, IT Department" -G developers,sudo -u 1500 john

# Проверка созданного пользователя
id john
```

### Ключевые флаги `useradd`

| Опция             | Описание                                                               | Пример использования            |
| ----------------- | ---------------------------------------------------------------------- | ------------------------------- |
| `-m`              | Создать домашнюю директорию (`/home/username`)                         | `useradd -m john`               |
| `-M`              | Не создавать домашнюю директорию (даже если настроено по умолчанию)    | `useradd -M john`               |
| `-s <shell>`      | Указать оболочку по умолчанию                                          | `useradd -s /bin/zsh john`      |
| `-g <group>`      | Указать основную группу (GID)                                          | `useradd -g developers john`    |
| `-G <groups>`     | Список дополнительных групп через запятую                              | `useradd -G docker,sudo john`   |
| `-c "<comment>"`  | GECOS-поле (описание, полное имя, контакт)                             | `useradd -c "John Smith" john`  |
| `-u <UID>`        | Явно задать UID (редко, для совместимости между системами)             | `useradd -u 1500 john`          |
| `-r`              | Создать системного пользователя (UID 100-999, без домашней директории) | `useradd -r nginx`              |
| `-d <path>`       | Указать путь к домашней директории (вместо `/home/user`)               | `useradd -d /srv/john john`     |
| `-e <YYYY-MM-DD>` | Дата истечения срока действия аккаунта                                 | `useradd -e 2027-01-01 john`    |
| `-N`              | Не создавать одноимённую группу для пользователя                       | `useradd -N -g developers john` |

### Автоматическое создание группы

При создании нового пользователя в Linux автоматически создается одноименная группа. Эта стандартная политика безопасности называется **User Private Group (UPG)**.

**Как это работает:**

- **Главная группа:** По умолчанию создается группа с тем же именем, что и логин. Пользователь автоматически становится ее единственным участником.
- **Права доступа:** Эта схема обеспечивает безопасные настройки по умолчанию: созданные файлы доступны только этому пользователю и его группе.
