## Цель работы

Научиться устанавливать WireGuard, создавать ключи, настраивать VPN-сервер и VPN-клиент на Ubuntu Server, устанавливать защищённое соединение и проверять его работу.

## Предварительная информация

- **Proxmox:** `http://proxmox.ggkit.local:8006`.
- **Шаблон:** `students-ubuntu26.04-template`.
- Создайте **два полных клона (Full Clone)** шаблона:
  - `oaks-practicheskaya-rabota-4-server` — VPN-сервер;
  - `oaks-practicheskaya-rabota-4-client` — VPN-клиент.
- **Логин на обеих ВМ:** `user`.
- **Пароль:** `P@ssw0rd`.
- Обе виртуальные машины должны быть подключены к одной доступной сети Proxmox и иметь IP-адреса. Адреса назначаются существующим DHCP-сервером.
- В этой работе VPN создаётся **между двумя ВМ в лабораторной сети**. Публичный IP, проброс портов и доступ к интернету через VPN не требуются.
- **VPN-адрес сервера:** `10.8.0.1/24`.
- **VPN-адрес клиента:** `10.8.0.2/24`.
- **Порт WireGuard:** UDP `51820`.
- Для простоты используем **Split Tunnel**: через VPN передаётся только трафик к VPN-подсети `10.8.0.0/24`.

> **Важно:** Команды выполняйте на той ВМ, которая указана в задании. Закрытые ключи (`*.key`) не включайте в отчёт и не передавайте другим людям. В отчёте можно показывать открытые ключи (`*.pub`), но не содержимое строки `PrivateKey`.

## Требования к отчёту

Отчёт оформляется в **LibreOffice Writer**. Имя файла: `PR4-Имя_Фамилия.odt`.

1. **Титульный лист:** номер и название практической работы, ФИО и группа.
2. **Вторая страница:** цель работы и перечень заданий.
3. **Далее каждое задание с новой страницы:** что выполнено, использованные команды, читаемые скриншоты результатов и краткие пояснения.
4. **Последняя страница:** ответы на вопросы для защиты.

Отчёт необходимо загрузить в `Сеть для лабораторий/308а/С1.23.41`.

## Критерии оценки

- Две ВМ созданы и доступны по сети.
- WireGuard установлен на сервере и клиенте.
- Для каждой ВМ создана отдельная пара ключей.
- Конфигурации содержат правильные адреса, ключи и параметры.
- VPN запускается, обмен пакетами и `ping` работают.
- Отчёт содержит команды, результаты и ответы на вопросы.

# Задания

## Задание 1. Создание виртуальных машин и проверка сети

**Цель:** Подготовить сервер и клиент и убедиться, что они доступны друг другу.

1. В Proxmox создайте два полных клона шаблона `students-ubuntu26.04-template` с именами, указанными выше.
2. Запустите обе ВМ, войдите под пользователем `user`.
3. На сервере установите имя компьютера `wg-server`, на клиенте — `wg-client`.
4. На каждой ВМ выполните `ip -c -br a` и запишите IPv4-адрес основного сетевого интерфейса (не `lo`).
5. На клиенте проверьте доступность основного IP-адреса сервера с помощью `ping -c 4`.

**Что отразить в отчёте:** Скриншот обеих ВМ в Proxmox, IP-адреса, результаты `ping`. Укажите, какой адрес будет использоваться для подключения клиента к серверу.

## Задание 2. Установка WireGuard

**Цель:** Установить WireGuard на обеих ВМ.

1. На сервере и клиенте обновите список пакетов.
2. Установите пакет `wireguard`.
3. Проверьте наличие утилиты `wg` командой `wg --version`.

**Что отразить в отчёте:** Команды установки и вывод версии WireGuard на обеих ВМ.

## Задание 3. Создание ключей WireGuard

**Цель:** Создать отдельные криптографические ключи сервера и клиента.

1. На **сервере** создайте каталог `/etc/wireguard` с ограниченными правами.
2. Создайте файлы `server.key` (закрытый ключ) и `server.pub` (открытый ключ).
3. На **клиенте** создайте каталог `/etc/wireguard` и файлы `client.key`, `client.pub`.
4. Выведите **только открытые ключи** и обменяйтесь ими: серверу нужен открытый ключ клиента, клиенту — открытый ключ сервера.
5. Убедитесь, что файлы закрытых ключей не доступны обычным пользователям для чтения.

**Что отразить в отчёте:** Команды генерации, имена созданных файлов и открытые ключи. Закрытые ключи и значения `PrivateKey` не показывайте.

## Задание 4. Настройка WireGuard-сервера

**Цель:** Создать конфигурацию сервера и запустить VPN-интерфейс.

1. На сервере создайте `/etc/wireguard/wg0.conf`.
2. Укажите в секции `[Interface]` адрес `10.8.0.1/24`, порт `51820` и закрытый ключ **сервера**.
3. В секции `[Peer]` укажите открытый ключ **клиента** и `AllowedIPs = 10.8.0.2/32`.
4. Установите права `600` на файл конфигурации.
5. Запустите `wg0` командой `sudo wg-quick up wg0`.
6. Проверьте интерфейс с помощью `ip -c -br a` и `sudo wg show`.
7. Включите автоматический запуск WireGuard через systemd.

**Что отразить в отчёте:** Конфигурацию **с замаскированным PrivateKey**, команды запуска, наличие `wg0` с адресом `10.8.0.1`, вывод `wg show`.

## Задание 5. Настройка WireGuard-клиента

**Цель:** Настроить подключение клиента к VPN-серверу.

1. На клиенте создайте `/etc/wireguard/wg0.conf`.
2. В `[Interface]` укажите `Address = 10.8.0.2/24` и закрытый ключ **клиента**.
3. В `[Peer]` укажите открытый ключ **сервера**.
4. В `Endpoint` укажите **основной IP-адрес сервера из задания 1** и порт `51820`.
5. Укажите `AllowedIPs = 10.8.0.0/24` и `PersistentKeepalive = 25`.
6. Установите права `600` на конфигурацию.
7. Запустите `wg0` и проверьте, что появился интерфейс с адресом `10.8.0.2`.

**Что отразить в отчёте:** Конфигурацию без закрытого ключа, команды запуска и вывод `ip -c -br a`.

## Задание 6. Проверка VPN-соединения

**Цель:** Проверить, что сервер и клиент обмениваются данными по защищённому туннелю.

1. На **клиенте** выполните `ping -c 4 10.8.0.1`.
2. На **сервере** выполните `ping -c 4 10.8.0.2`.
3. На обеих ВМ выполните `sudo wg show`.
4. Найдите поля `latest handshake` и `transfer`. Убедитесь, что обмен ключами состоялся и счётчики трафика увеличились.
5. На клиенте выполните `ip route get 10.8.0.1` и убедитесь, что маршрут использует `wg0`.
6. На клиенте выключите VPN командой `sudo wg-quick down wg0`, затем снова включите `sudo wg-quick up wg0` и повторите `ping`.

**Что отразить в отчёте:** Результаты обоих `ping`, `wg show`, маршрут до сервера, повторную проверку после перезапуска VPN.

# Реализация заданий

> В примерах основной адрес сервера — `192.168.1.10`. **Замените его реальным адресом вашей серверной ВМ из задания 1.** Значения открытых ключей у каждой пары ВМ будут уникальными.

## Задание 1

В Proxmox создайте две ВМ и запустите их.

На **сервере**:

```bash
sudo hostnamectl set-hostname wg-server
ip -c -br a
```

На **клиенте**:

```bash
sudo hostnamectl set-hostname wg-client
ip -c -br a
ping -c 4 192.168.1.10
```

## Задание 2

На **обеих ВМ**:

```bash
sudo apt update
sudo apt install wireguard -y
wg --version
```

## Задание 3

На **сервере**:

```bash
sudo install -d -m 700 /etc/wireguard
sudo sh -c 'umask 077; wg genkey > /etc/wireguard/server.key'
sudo sh -c 'wg pubkey < /etc/wireguard/server.key > /etc/wireguard/server.pub'
sudo cat /etc/wireguard/server.pub
sudo ls -l /etc/wireguard/
```

На **клиенте**:

```bash
sudo install -d -m 700 /etc/wireguard
sudo sh -c 'umask 077; wg genkey > /etc/wireguard/client.key'
sudo sh -c 'wg pubkey < /etc/wireguard/client.key > /etc/wireguard/client.pub'
sudo cat /etc/wireguard/client.pub
sudo ls -l /etc/wireguard/
```

Скопируйте **открытый ключ клиента** для конфигурации сервера и **открытый ключ сервера** для конфигурации клиента. Не выводите закрытые ключи на экран ради отчёта.

## Задание 4

На **сервере** откройте конфигурацию:

```bash
sudo nano /etc/wireguard/wg0.conf
```

Содержимое (замените значения в угловых скобках на соответствующие ключи):

```ini
[Interface]
Address = 10.8.0.1/24
ListenPort = 51820
PrivateKey = <ЗАКРЫТЫЙ_КЛЮЧ_СЕРВЕРА>

[Peer]
PublicKey = <ОТКРЫТЫЙ_КЛЮЧ_КЛИЕНТА>
AllowedIPs = 10.8.0.2/32
```

Для вставки значения `PrivateKey` используйте содержимое файла `/etc/wireguard/server.key`, созданного на сервере. **Не вставляйте путь к файлу вместо значения ключа.** Чтобы посмотреть значение при настройке, используйте `sudo cat /etc/wireguard/server.key` только в личной консоли, не делайте скриншот и не копируйте вывод в отчёт.

Сохраните файл (`Ctrl+O`, `Enter`, `Ctrl+X`) и выполните:

```bash
sudo chmod 600 /etc/wireguard/wg0.conf
sudo wg-quick up wg0
ip -c -br a
sudo wg show
sudo systemctl enable wg-quick@wg0
```

## Задание 5

На **клиенте**:

```bash
sudo nano /etc/wireguard/wg0.conf
```

Конфигурация:

```ini
[Interface]
Address = 10.8.0.2/24
PrivateKey = <ЗАКРЫТЫЙ_КЛЮЧ_КЛИЕНТА>

[Peer]
PublicKey = <ОТКРЫТЫЙ_КЛЮЧ_СЕРВЕРА>
Endpoint = 192.168.1.10:51820
AllowedIPs = 10.8.0.0/24
PersistentKeepalive = 25
```

Замените `192.168.1.10` реальным основным IP-адресом серверной ВМ, а значения ключей — соответствующими ключами. Для `PrivateKey` используйте содержимое `/etc/wireguard/client.key` на клиенте; для `PublicKey` — содержимое `/etc/wireguard/server.pub` с сервера.

```bash
sudo chmod 600 /etc/wireguard/wg0.conf
sudo wg-quick up wg0
ip -c -br a
sudo wg show
```

## Задание 6

На **клиенте**:

```bash
ping -c 4 10.8.0.1
sudo wg show
ip route get 10.8.0.1
```

На **сервере**:

```bash
ping -c 4 10.8.0.2
sudo wg show
```

На **клиенте** повторно запустите VPN:

```bash
sudo wg-quick down wg0
sudo wg-quick up wg0
ping -c 4 10.8.0.1
```

Успешный результат: `ping` проходит в обе стороны, а `sudo wg show` после обмена пакетами показывает `latest handshake` и ненулевые значения `transfer`.

Если `ping` не проходит, сначала проверьте основной IP сервера, доступность сервера по обычной сети, правильность открытых ключей, адреса `Endpoint` и состояние интерфейса `wg0` на обеих ВМ. Если на сервере включён UFW, проверьте разрешение входящих UDP-пакетов на порт `51820`.
