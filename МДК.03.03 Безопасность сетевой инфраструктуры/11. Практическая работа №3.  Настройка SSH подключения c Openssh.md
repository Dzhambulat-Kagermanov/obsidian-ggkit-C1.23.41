## Задания

### Задание 1. Первоначальное подключение и изучение `known_hosts`

**Цель:** Получить IP-адреса виртуальных машин, установить первое соединение и понять механизм проверки хостового ключа.

1. Войдите в обе виртуальные машины (`client` и `server`) через консоль Proxmox.
2. На обеих машинах выполните команду для просмотра IP-адреса:

```bash
ip -c -br a
```

_(Запишите IP-адрес bsi-practicheskaya-rabota-3-server, он понадобится далее. Допустим, это `192.168.1.50`)_.

3. На машине **client** попытайтесь подключиться к серверу по паролю:

```bash
ssh user@<IP_адрес_сервера>
```

_Можно посмотреть что knowk_hosts изначально пустой_

```bash
cat ~/.ssh/known_hosts
```

4. При первом подключении система выдаст предупреждение о невозможности проверить подлинность хоста. Введите `yes` для продолжения.
5. Введите пароль `P@ssw0rd`.
6. Успешно войдя на сервер, выполните команду `exit` для возврата на клиент.
7. На машине **client** просмотрите содержимое файла доверенных хостов:

```bash
cat ~/.ssh/known_hosts
```

**Что отразить в отчёте:** Скриншот процесса первого подключения с предупреждением, вывод команды `cat ~/.ssh/known_hosts` и краткое объяснение, зачем нужен этот файл (защита от MITM-атаки).

### Задание 2. Настройка аутентификации по ключу (Ed25519)

**Цель:** Отказаться от небезопасного ввода пароля и настроить вход по криптографическому ключу.

1. На машине **client** сгенерируйте пару ключей Ed25519 с комментарием (укажите свою фамилию-имя за место **student**):

```bash
ssh-keygen -t ed25519 -C "student@lab.local" -f ~/.ssh/id_ed25519
```

_(Нажмите Enter, чтобы не устанавливать passphrase, так как это учебная среда)._

2. Установите строгие права доступа на файлы ключей (это обязательное требование SSH):

```bash
chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_ed25519
chmod 644 ~/.ssh/id_ed25519.pub
```

3. Скопируйте публичный ключ на сервер с помощью утилиты `ssh-copy-id` (потребуется ввести пароль один раз):

```
ssh-copy-id -i ~/.ssh/id_ed25519.pub user@<IP_адрес_сервера>
```
