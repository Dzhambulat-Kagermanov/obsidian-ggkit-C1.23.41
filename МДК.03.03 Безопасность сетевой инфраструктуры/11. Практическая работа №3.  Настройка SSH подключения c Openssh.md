## Цель работы:

Научиться настраивать безопасное удалённое управление по протоколу SSH: выполнять первоначальное подключение, генерировать и применять асимметричные ключи шифрования (Ed25519), настраивать конфигурационные файлы клиента и сервера для повышения безопасности, а также осуществлять передачу файлов с помощью SCP.

## Предварительная информация

Вся необходимая информация перед выполнением задания:

- У каждого пользователя есть свои учетные данные: логин и пароль.
- **Proxmox стенд:** http://proxmox.ggkit.local:8006
- Для создания виртуальной машины у каждого студента доступен шаблон `students-ubuntu26.04-template`. Его можно склонировать и создать виртуалку `Ubuntu 26.04`.
- Учетные данные от склонированной виртуальной машины:
    - Логин: `user`
    - Пароль: `P@ssw0rd`
- Для выполнения задания нужно склонировать **две** виртуалки. Склонированные ВМ нужно назвать:
    - `bsi-practicheskaya-rabota-3-client`
    - `bsi-practicheskaya-rabota-3-server`
- В сети поднят DHCP-сервер. Для узнавания IP-адресов используйте команду `ip -c -br a`.
- По окончанию выполнения заданий должен быть составлен отчет, по которому оценивается работа. Без него будет считаться, что работа не сдана.
- Отчет следует назвать согласно требованиям к отчету.
- Отчет закидывается в `Сеть для лабораторий/308а/С1.23.41`.

## Требования к отчёту в LibreOffice Writer

Отчёт оформляется в **LibreOffice Writer**. Имя файла:  
`PR3-Имя_Фамилия.odt`

Структура отчёта:

1. **Титульный лист**
    - номер и название практической работы: «Практическая работа №3. Настройка безопасного удаленного доступа по протоколу SSH»;
    - ФИО студента;
    - группа.
2. **Вторая страница: все задания**
    - Скопировать цель работы.
3. **Далее: решение каждого задания с новой страницы**  
    Для каждого задания:
    - заголовок: `Задание 1. ...`;
    - краткое описание: что делали и зачем;
    - команды, которые выполняли;
    - результат: вывод команд, скриншоты или фото экрана.

Скриншоты и фото должны быть читаемыми. Для каждой команды лучше показать и текстовый вывод, и скриншот.

## Критерии оценки

- Все задания выполнены.
- В отчёте есть команды, результат и ответы на вопросы «зачем?».
- Студент понимает, что делает каждая команда.
- Оформление соответствует требованиям LibreOffice Writer.

## Задания

### Задание 1. Первоначальное подключение и изучение `known_hosts`

**Цель:** Получить IP-адреса виртуальных машин, установить первое соединение и понять механизм проверки хостового ключа.

1. Войдите в обе виртуальные машины (`client` и `server`) через консоль Proxmox.
2. На обеих машинах выполните команду для просмотра IP-адреса:

```bash
ip -c -br a
```

_(Запишите IP-адрес bsi-pra, он понадобится далее. Допустим, это `192.168.1.50`)_.
