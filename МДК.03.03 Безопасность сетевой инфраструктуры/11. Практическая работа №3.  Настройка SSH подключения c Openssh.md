## Цель работы:

Научиться безопасно подключаться к удаленным серверам по протоколу SSH, настраивать аутентификацию по криптографическим ключам, конфигурировать клиент SSH для удобства работы, осуществлять безопасную передачу файлов с помощью SCP и применять базовые меры защиты на стороне SSH-сервера.

## Предварительная информация

Вся необходимая информация перед выполнением задания:

- У каждого пользователя есть свои учетные данные: логин и пароль.
- **Proxmox стенд:** http://proxmox.ggkit.local:8006
- Для создания виртуальной машины у каждого студента доступен шаблон `students-ubuntu26.04-template`. Его можно склонировать и создать виртуалку `Ubuntu 26.04`.
- Учетные данные от склонированной виртуальной машины:
    - Логин: `user`
    - Пароль: `P@ssw0rd`
- Склонированную ВМ нужно назвать `bsi-practicheskaya-rabota-3`
- По окончанию выполнения заданий должен быть составлен отчет, по которому оценивается работа. Без него будет считаться, что работа не сдана.
- Отчет следует назвать своим ФИО.
- Отчет закидывается в `Сеть для лабараторий/308а/С1.23.41`

## Требования к отчёту в LibreOffice Writer

Отчёт оформляется в **LibreOffice Writer**. Имя файла:  
`PR3-Имя_Фамилия.odt`

Структура отчёта:

1. **Титульный лист**
    - номер и название практической работы:  
        «Практическая работа №3. Настройка SSH подключения c Openssh» ;
    - ФИО студента;
    - группа;
    
2. **Вторая страница:**
    - Скопировать цель работы
    
3. **Далее: решение каждого задания с новой страницы**  
    Для каждого задания:
    - заголовок: например, `Задание 1. Сбор информации о текущем пользователе и системе`;
    - краткое описание: что делали и зачем;
    - команды, которые выполняли;
    - результат: вывод команд, скриншоты или фото экрана;

Скриншоты и фото должны быть читаемыми. Для каждой команды лучше показать и текстовый вывод, и скриншот.

## Критерии оценки

- Все задания выполнены.
- В отчёте есть команды, результат и ответы на вопросы «зачем?».
- Студент понимает, что делает каждая команда.
- Оформление соответствует требованиям LibreOffice Writer.
