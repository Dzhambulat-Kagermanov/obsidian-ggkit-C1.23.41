## Задания

### Задание 1. Кто я и какие у меня группы?

Выполните:

```bash
whoami
id
groups
getent passwd $USER
```

Запишите в отчёт:

- имя текущего пользователя;
- UID, GID, основную и дополнительные группы;
- строку из `/etc/passwd` для текущего пользователя.

**Ответьте:**  
Чем обычный пользователь отличается от `root`? Зачем вообще нужны группы?

### Задание 2. Создать группу для отдела

Создайте группы:

```bash
sudo groupadd grp_ivanov_dev
sudo groupadd grp_ivanov_ops
```

Проверьте:

```bash
getent group grp_ivanov_dev
getent group grp_ivanov_ops
```

Запишите GID каждой группы.

**Ответьте:**  
Зачем создавать группу, если есть пользователи? Почему удобно давать права не каждому человеку отдельно, а группе?

### Задание 3. Создать нового пользователя (сотрудника)

Создайте пользователя `prac_ivanov_u1`:

```bash
sudo useradd -m -s /bin/bash -g grp_ivanov_dev -G grp_ivanov_ops -c "Ivanov User One" prac_ivanov_u1
sudo passwd prac_ivanov_u1
```

Создайте второго пользователя `prac_ivanov_u2` для проверки прав:

```bash
sudo useradd -m -s /bin/bash prac_ivanov_u2
sudo passwd prac_ivanov_u2
```

Проверьте:

```bash
id prac_ivanov_u1
id prac_ivanov_u2
getent passwd prac_ivanov_u1
ls -ld /home/prac_ivanov_u1 /home/prac_ivanov_u2
```

Запишите:

- UID и GID;
- домашние директории;
- оболочку;
- комментарий;
- список групп.

**Ответьте:**  
Что делает флаг `-m`? Что делает `-s`? Что делает `-g`? Что делает `-G`? Зачем пользователю домашняя директория?

### Задание 4. Изменить пользователя

Выполните:

```bash
sudo usermod -c "Ivanov User One, DevOps" prac_ivanov_u1
getent passwd prac_ivanov_u1

sudo usermod -s /bin/sh prac_ivanov_u1
getent passwd prac_ivanov_u1

sudo usermod -s /bin/bash prac_ivanov_u1
getent passwd prac_ivanov_u1
```

Добавьте пользователя в дополнительную группу:

```bash
sudo usermod -aG grp_ivanov_ops prac_ivanov_u1
groups prac_ivanov_u1
```

Проверьте опасный вариант без `-a`:

```bash
sudo usermod -G grp_ivanov_dev prac_ivanov_u1
groups prac_ivanov_u1
```

Верните группу обратно:

```bash
sudo usermod -aG grp_ivanov_ops prac_ivanov_u1
groups prac_ivanov_u1
```

Заблокируйте и разблокируйте пользователя:

```bash
sudo usermod -L prac_ivanov_u1
sudo passwd -S prac_ivanov_u1

sudo usermod -U prac_ivanov_u1
sudo passwd -S prac_ivanov_u1
```

**Ответьте:**  
Почему при добавлении в группу нужно писать `-aG`, а не просто `-G`? Что происходит с пользователем при `-L`? Как проверить, что он заблокирован?

### Задание 5. Управление паролем

Выполните:

```bash
sudo passwd prac_ivanov_u2
sudo passwd -l prac_ivanov_u2
sudo passwd -S prac_ivanov_u2

sudo passwd -u prac_ivanov_u2
sudo passwd -S prac_ivanov_u2
```

Запишите вывод `passwd -S` и расшифруйте его.

**Ответьте:**  
Почему Linux не хранит пароли в открытом виде? Что означает символ `!` в `/etc/shadow`? Чем блокировка пароля отличается от удаления пользователя?

### Задание 6. Права на файлы

Создайте тестовую папку и файлы:

```bash
sudo mkdir -p /srv/prac_ivanov
sudo chown root:root /srv/prac_ivanov
sudo chmod 755 /srv/prac_ivanov

echo "file1" | sudo tee /srv/prac_ivanov/file1.txt
echo "file2" | sudo tee /srv/prac_ivanov/file2.txt
printf '#!/bin/bash\necho hello\n' | sudo tee /srv/prac_ivanov/script.sh

sudo chown prac_ivanov_u1:grp_ivanov_dev /srv/prac_ivanov/file1.txt
sudo chown prac_ivanov_u1:grp_ivanov_dev /srv/prac_ivanov/file2.txt
sudo chown prac_ivanov_u1:grp_ivanov_dev /srv/prac_ivanov/script.sh
```

Посмотрите права:

```bash
ls -l /srv/prac_ivanov
```

Установите права:

```bash
sudo chmod 644 /srv/prac_ivanov/file1.txt
sudo chmod 600 /srv/prac_ivanov/file2.txt
sudo chmod 755 /srv/prac_ivanov/script.sh
ls -l /srv/prac_ivanov
```

Проверьте доступ от второго пользователя:

```bash
sudo -u prac_ivanov_u2 cat /srv/prac_ivanov/file1.txt
sudo -u prac_ivanov_u2 cat /srv/prac_ivanov/file2.txt
sudo -u prac_ivanov_u2 /srv/prac_ivanov/script.sh
```

**Ответьте:**  
Что означает `644`? Что означает `600`? Что означает `755`? Почему `file1.txt` читается другим пользователем, а `file2.txt` — нет?

### Задание 7. Права на директорию

Создайте директорию:

```bash
sudo mkdir /srv/prac_ivanov/dir1
sudo chown prac_ivanov_u1:grp_ivanov_dev /srv/prac_ivanov/dir1
sudo chmod 700 /srv/prac_ivanov/dir1
ls -ld /srv/prac_ivanov/dir1
```

Проверьте доступ:

```bash
sudo -u prac_ivanov_u2 ls /srv/prac_ivanov/dir1
sudo -u prac_ivanov_u2 bash -c 'cd /srv/prac_ivanov/dir1 && pwd'
```

Измените права:

```bash
sudo chmod 755 /srv/prac_ivanov/dir1
ls -ld /srv/prac_ivanov/dir1
sudo -u prac_ivanov_u2 ls /srv/prac_ivanov/dir1
```

**Ответьте:**  
Почему для входа в директорию нужен `x`? Почему удаление файла зависит от прав на директорию, а не от прав на сам файл? Чем `r`, `w`, `x` для папки отличаются от `r`, `w`, `x` для файла?

### Задание 8. Изменить владельца и группу

Выполните:

```bash
sudo chown prac_ivanov_u2:grp_ivanov_ops /srv/prac_ivanov/file1.txt
ls -l /srv/prac_ivanov/file1.txt

sudo chgrp grp_ivanov_dev /srv/prac_ivanov/file1.txt
ls -l /srv/prac_ivanov/file1.txt
```

**Ответьте:**  
Чем отличается `chown` от `chgrp`? Почему обычный пользователь не может просто так отдать свой файл другому?

### Задание 9. Простой `sudo`

Добавьте пользователя в группу администраторов `sudo`. Проверьте что группа есть в системе:

```bash
getent group sudo
```

Добавьте в существующую группу:

```bash
sudo usermod -aG sudo prac_ivanov_u1
# или
sudo usermod -aG wheel prac_ivanov_u1
```

Проверьте:

```bash
groups prac_ivanov_u1
sudo -l -U prac_ivanov_u1
```

Выполните команду от имени нового пользователя:

```bash
su - prac_ivanov_u1 -c 'sudo whoami'
```

**Ответьте:**  
Зачем нужен `sudo`, если можно работать под `root`? Почему не дают всем пароль `root`? Что значит «делегировать права»?

### Задание 10. Удалить пользователей и группы

Создайте временного пользователя:

```bash
sudo useradd -m -s /bin/bash prac_ivanov_temp
sudo passwd prac_ivanov_temp
ls -ld /home/prac_ivanov_temp
```

Удалите без `-r`:

```bash
sudo userdel prac_ivanov_temp
ls -ld /home/prac_ivanov_temp
```

Создайте второго временного и удалите с `-r`:

```bash
sudo useradd -m -s /bin/bash prac_ivanov_temp2
sudo userdel -r prac_ivanov_temp2
ls -ld /home/prac_ivanov_temp2
```

Удалите основных пользователей и группы:

```bash
sudo userdel -r prac_ivanov_u1
sudo userdel -r prac_ivanov_u2

sudo groupdel grp_ivanov_dev
sudo groupdel grp_ivanov_ops

sudo rm -rf /srv/prac_ivanov
```

**Ответьте:**  
Чем `userdel` отличается от `userdel -r`? В каком случае домашнюю директорию лучше сохранить? Почему нельзя удалить группу, если она основная для пользователя?
