
## Задание 4. Изменить пользователя

Выполните:

```bash
sudo usermod -c "Ivanov User One, DevOps" prac_ivanov_u1
getent passwd prac_ivanov_u1

sudo usermod -s /bin/sh prac_ivanov_u1
getent passwd prac_ivanov_u1

sudo usermod -s /bin/bash prac_ivanov_u1
getent passwd prac_ivanov_u1
```

Добавьте пользователя в дополнительную группу:

```bash
sudo usermod -aG grp_ivanov_ops prac_ivanov_u1
groups prac_ivanov_u1
```

Проверьте опасный вариант без `-a`:

```bash
sudo usermod -G grp_ivanov_dev prac_ivanov_u1
groups prac_ivanov_u1
```

Верните группу обратно:

```bash
sudo usermod -aG grp_ivanov_ops prac_ivanov_u1
groups prac_ivanov_u1
```

Заблокируйте и разблокируйте пользователя:

```bash
sudo usermod -L prac_ivanov_u1
sudo passwd -S prac_ivanov_u1

sudo usermod -U prac_ivanov_u1
sudo passwd -S prac_ivanov_u1
```

**Ответьте:**  
Почему при добавлении в группу нужно писать `-aG`, а не просто `-G`? Что происходит с пользователем при `-L`? Как проверить, что он заблокирован?
