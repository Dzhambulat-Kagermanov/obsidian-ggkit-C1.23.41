## Задание 2. Разметка диска 10 GB и создание файловой системы

На дополнительном диске объёмом 10 GB создайте два раздела: первый размером 4 GB, второй — на всё оставшееся пространство.

Откройте `fdisk` (если диск имеет другое имя, замените `/dev/sdb`):

```bash
sudo fdisk /dev/sdb
```

В интерактивном режиме последовательно выполните:

```text
g                  # создать таблицу разделов GPT
n                  # создать первый раздел
Enter              # номер раздела по умолчанию
Enter              # первый сектор по умолчанию
+4G                # размер первого раздела
n                  # создать второй раздел
Enter              # номер раздела по умолчанию
Enter              # первый сектор по умолчанию
Enter              # последний сектор: всё оставшееся место
p                  # показать результат разметки
w                  # записать изменения и выйти
```

Проверьте разделы, создайте на них файловую систему `ext4`:

```bash
sudo partprobe /dev/sdb
sudo udevadm settle

lsblk /dev/sdb

sudo mkfs.ext4 /dev/sdb1
sudo mkfs.ext4 /dev/sdb2

lsblk -f /dev/sdb
```

**Что отразить в отчёте:** таблицу разделов после `fdisk`, размеры `/dev/sdb1` и `/dev/sdb2`, тип файловой системы `ext4`.

## Задание 3. Монтирование и настройка /etc/fstab

Создайте два каталога и смонтируйте созданные разделы:

```bash
sudo mkdir -p /srv/data1 /srv/data2

sudo mount /dev/sdb1 /srv/data1
sudo mount /dev/sdb2 /srv/data2

df -hT /srv/data1 /srv/data2
```

Для автоматического подключения после перезагрузки используйте UUID разделов:

```bash
sudo blkid /dev/sdb1 /dev/sdb2

sudo nano /etc/fstab
```

Добавьте в конец файла **две строки**, подставив реальные UUID из вывода `blkid`. (Внимательно следите за fstab нельзя допускать ошибки):

```fstab
UUID=<UUID_ПЕРВОГО_РАЗДЕЛА> /srv/data1 ext4 defaults 0 2
UUID=<UUID_ВТОРОГО_РАЗДЕЛА> /srv/data2 ext4 defaults 0 2
```

Сохраните файл (`Ctrl+O`, `Enter`, `Ctrl+X`). Проверьте конфигурацию **до перезагрузки**:

```bash
sudo systemctl daemon-reload

sudo findmnt --verify

sudo umount /srv/data1 /srv/data2

sudo mount -a

findmnt /srv/data1
findmnt /srv/data2
```

Если проверка сообщает об ошибке, исправьте `/etc/fstab` и не перезагружайте ВМ до устранения проблемы.

После успешной проверки перезагрузите машину и убедитесь, что оба раздела смонтировались автоматически:

```bash
sudo reboot
```

После повторного входа:

```bash
findmnt /srv/data1
findmnt /srv/data2
```

**Что отразить в отчёте:** UUID разделов, две строки `/etc/fstab`, результат проверки и наличие монтирования после перезагрузки.

## Задание 4. Создание LVM на диске 4 GB

Установите инструменты LVM:

```bash
sudo apt update
sudo apt install lvm2 -y
```

На **дополнительном диске 4 GB** создайте один раздел, занимающий всё пространство:

```bash
sudo fdisk /dev/sdc
```

Внутри `fdisk` введите `g`, затем `n`, трижды нажмите `Enter` для значений по умолчанию и введите `w`.

Обновите сведения о разделах:

```bash
sudo partprobe /dev/sdc
sudo udevadm settle

lsblk /dev/sdc
```

Создайте физический том PV, группу томов VG и логический том LV размером **2 GB**:

```bash
sudo pvcreate /dev/sdc1

sudo vgcreate vg_storage /dev/sdc1

sudo lvcreate -L 2G -n lv_data vg_storage

sudo pvs
sudo vgs
sudo lvs
```

Создайте файловую систему и подключите логический том:

```bash
sudo mkfs.ext4 /dev/vg_storage/lv_data

sudo mkdir -p /srv/storage

sudo mount /dev/vg_storage/lv_data /srv/storage

df -hT /srv/storage
```

Создайте контрольный файл, чтобы проверить его сохранность после расширения:

```bash
echo 'LVM test file' | sudo tee /srv/storage/check.txt

cat /srv/storage/check.txt
```

**Что отразить в отчёте:** вывод `pvs`, `vgs`, `lvs`, размер смонтированного тома и содержимое `check.txt`.

## Задание 5. Расширение LVM с помощью диска 7 GB

На **дополнительном диске 7 GB** создайте один раздел на всё доступное пространство:

```bash
sudo fdisk /dev/sdd
```

Внутри `fdisk` введите `g`, затем `n`, трижды нажмите `Enter` и введите `w`.

```bash
sudo partprobe /dev/sdd
sudo udevadm settle

lsblk /dev/sdd
```

Подготовьте новый физический том и добавьте его в существующую группу:

```bash
sudo pvcreate /dev/sdd1

sudo vgextend vg_storage /dev/sdd1

sudo pvs
sudo vgs
```

Увеличьте логический том **на 5 GB** и одновременно расширьте файловую систему с помощью параметра `-r`:

```bash
sudo lvextend -r -L +5G /dev/vg_storage/lv_data

sudo lvs
df -hT /srv/storage

cat /srv/storage/check.txt
```

Размер логического тома должен увеличиться с 2 GB до **7 GB**. Контрольный файл должен сохраниться. Отдельно выполнять `resize2fs` после успешного `lvextend -r` не требуется.

**Что отразить в отчёте:** два физических тома в `pvs`, увеличенную группу в `vgs`, новый размер LV и файловой системы, сохранившийся `check.txt`.

## Задание 6. Проверка результата и автоматическое монтирование LVM

Настройте автоматическое монтирование логического тома:

```bash
sudo blkid /dev/vg_storage/lv_data

sudo nano /etc/fstab
```

Добавьте строку с реальным UUID логического тома:

```fstab
UUID=<UUID_ЛОГИЧЕСКОГО_ТОМА> /srv/storage ext4 defaults 0 2
```

Проверьте настройки:

```bash
sudo systemctl daemon-reload

sudo findmnt --verify

sudo umount /srv/storage

sudo mount -a

findmnt /srv/storage
```

Если ошибок нет, перезагрузите ВМ:

```bash
sudo reboot
```

После повторного входа выполните:

```bash
lsblk -f
sudo pvs
sudo vgs
sudo lvs
df -hT /srv/data1 /srv/data2 /srv/storage
cat /srv/storage/check.txt
```

**Что отразить в отчёте:** итоговую структуру дисков и LVM, три автоматически смонтированные файловые системы, содержимое контрольного файла после перезагрузки.
