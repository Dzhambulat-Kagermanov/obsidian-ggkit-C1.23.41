## Основы: сетевой интерфейс в Linux

**Сетевой интерфейс** — это точка подключения узла к сети. Бывает:
- **Физический** (`eth0`, `enp3s0`) — соответствует железу (NIC).
- **Виртуальный** (`lo`, `veth*`, `tap*`, `vmbr*`, `bond*`, `vlan*`, `ovs*`) — создаётся ядром/софтом.

Каждый интерфейс имеет:
- **MAC-адрес** — 48-битный идентификатор уровня L2 (например `52:54:00:12:34:56`).
- **IP-адрес** (опционально) — уровень L3.
- **Состояние** UP/DOWN.

### Просмотр интерфейсов

```bash
ip -c link show           # все интерфейсы + MAC + состояние

ip -c -br a               # IP адреса с состояниями

ip route show             # таблица маршрутизации
```

### Команда `ip`

```bash
# Включить/выключить интерфейс
sudo ip link set dev enp3s0 up
sudo ip link set dev enp3s0 down

# Сменить MAC
sudo ip link set dev enp3s0 address 02:11:22:33:44:55

# Назначить IP
sudo ip addr add 192.168.1.10/24 dev enp3s0
sudo ip addr del 192.168.1.10/24 dev enp3s0

# Маршрут по умолчанию
sudo ip route add default via 192.168.1.1
```

>[!warning] Всё, что сделано через `ip`, слетает после перезагрузки  
Для постоянства нужно записывать в Netplan или другой менеджер
