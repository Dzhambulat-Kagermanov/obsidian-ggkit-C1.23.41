Для работы выполнения команд допустим что есть следующие разделы.

| Устройство | Объём  | Назначение                   |
| ---------- | ------ | ---------------------------- |
| `/dev/sda` | 30 ГиБ | Системный диск, не изменяем  |
| `/dev/sdb` | 10 ГиБ | Разметка, ext4, монтирование |
| `/dev/sdc` | 8 ГиБ  | Первый диск LVM              |
| `/dev/sdd` | 12 ГиБ | Расширение LVM               |

Имена устройств являются примером. На конкретной виртуальной машине они могут отличаться.

## 1. Автоматическое монтирование файловых систем

### 1.1. Назначение автоматического монтирования

<mark style="background:#fff88f">Автоматическое монтирование — подключение файловой системы к заданному каталогу без ручного выполнения команды `mount` после каждой загрузки Linux.</mark>

При обычном монтировании:

```bash
sudo mount /dev/sdb1 /srv/data
```

<mark style="background:#fff88f">Файловая система подключается на время работы системы. После перезагрузки такое подключение обычно не восстанавливается само по себе. Для постоянного монтирования используется файл `/etc/fstab`.</mark>

<mark style="background:#fff88f">`/etc/fstab` (File Systems Table) — конфигурационный файл Linux, содержащий сведения о файловых системах, точках монтирования и параметрах их подключения.</mark>

Пример записи в `/etc/fstab`:

```bash
UUID=4f2a8d30-... /srv/data ext4 defaults 0 2
```

<mark style="background:#fff88f">Строка состоит из шести полей:</mark>

| <mark style="background:#fff88f">Поле</mark>        | <mark style="background:#fff88f">Назначение</mark>                     |
| --------------------------------------------------- | ---------------------------------------------------------------------- |
| <mark style="background:#fff88f">`UUID=...`</mark>  | <mark style="background:#fff88f">Идентификатор файловой системы</mark> |
| <mark style="background:#fff88f">`/srv/data`</mark> | <mark style="background:#fff88f">Точка монтирования</mark>             |
| <mark style="background:#fff88f">`ext4`</mark>      | <mark style="background:#fff88f">Тип файловой системы</mark>           |
### 1.2. Настройка автоматического монтирования

<mark style="background:#fff88f">Предположим, на разделе `/dev/sdb1` уже создана файловая система ext4.</mark>

<mark style="background:#fff88f">Получим UUID:</mark>

```bash
sudo blkid /dev/sdb1
```

Пример результата:

```bash
/dev/sdb1: UUID="4f2a8d30-..." TYPE="ext4"
```

<mark style="background:#fff88f">Создадим точку монтирования, если её ещё нет:</mark>

```bash
sudo mkdir -p /srv/data
```

Сохраним резервную копию конфигурации:

```bash
sudo cp /etc/fstab /etc/fstab.bak
```

Откроем файл:

```bash
sudo nano /etc/fstab
```

<mark style="background:#fff88f">Добавим в `/etc/fstab` строку с настоящим UUID:</mark>

```bash
UUID=ВАШ_UUID /srv/data ext4 defaults 0 2
```

Сохраним изменения.

>[!DANGER] <mark style="background:#fff88f">Опасность редактирования `/etc/fstab`</mark>
><mark style="background:#fff88f">Редактирование файла `/etc/fstab` (таблицы файловых систем в Linux) сопряжено с высоким риском, так как **любая ошибка в нем может привести к невозможности загрузки операционной системы**.</mark>
>
><mark style="background:#fff88f">После сохранения изменений выполните команду проверки fstab файла:</mark> 
>
>```bash
>findmnt --verify
>```
>
><mark style="background:#fff88f">Или можно проверить правильность fstab сразу смонтировав все диски</mark>
>
>```bash
>sudo mount -a
>```
><mark style="background:#fff88f">Эта команда пытается смонтировать всё, что описано в `fstab`. Если она выдаст ошибку — **исправляйте её немедленно**. Если команда выполнилась молча — всё в порядке, можно перезагружаться.</mark>

<mark style="background:#fff88f">После редактирования `/etc/fstab`:</mark>

```bash
sudo systemctl daemon-reload
```

## 2. Разметка дисков с помощью fdisk

### 2.1. Назначение fdisk

В отличие от команд, где вся операция задаётся одной строкой, `fdisk` открывает интерактивный интерфейс. Администратор последовательно выбирает действия и подтверждает запись изменений.

<mark style="background:#fff88f">Для просмотра дисков:</mark>

```bash
sudo fdisk -l
```

Для открытия конкретного диска:

```bash
sudo fdisk /dev/sdb
```

## 2.2. Основные команды fdisk

|Команда|Назначение|
|---|---|
|`m`|Показать справку|
|`p`|Показать текущую таблицу разделов|
|`g`|Создать таблицу GPT|
|`o`|Создать таблицу MBR|
|`n`|Создать раздел|
|`d`|Удалить раздел|
|`t`|Изменить тип раздела|
|`l`|Показать доступные типы разделов|
|`F`|Показать свободное пространство|
|`v`|Проверить таблицу разделов|
|`w`|Записать изменения на диск и выйти|
|`q`|Выйти без сохранения изменений|
