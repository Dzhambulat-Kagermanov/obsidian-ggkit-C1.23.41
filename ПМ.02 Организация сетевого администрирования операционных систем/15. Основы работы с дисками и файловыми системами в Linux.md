## 1. Как Linux работает с дисками

### 1.1. Диск, раздел, файловая система и точка монтирования

Представим, что мы подключили к серверу новый SSD на 100 ГБ.

Физически диск существует, Linux его обнаруживает, но пользователь ещё не может просто начать сохранять туда файлы. Между физическим устройством и обычной работой с файлами есть несколько уровней.

![[Снимок экрана 2026-11-01 234912.png]]

- **Диск** — устройство хранения данных. Это может быть HDD, SSD, NVMe-накопитель, виртуальный диск гипервизора или сетевое блочное устройство.
- **Раздел** — выделенная область диска. Один диск можно разделить на несколько независимых областей.
- **Файловая система** — способ организации файлов и каталогов на устройстве. Она определяет, как хранятся данные, имена файлов, права доступа и служебная информация.
- **Монтирование** — подключение файловой системы к определённой директории в общей структуре Linux.

### 1.2. Почему в Linux нет дисков C: и D:?

В Windows часто используется модель:

```
C:\Windows
D:\Documents
E:\Backup
```

В Linux существует единое дерево каталогов, начинающееся с корня `/`.

Например:

```
/
├── home
├── etc
├── dev
├── opt
├── var
├── tmp
└── mnt
```
