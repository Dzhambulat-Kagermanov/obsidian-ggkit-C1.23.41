# Задания

## Задание 1. Подготовка ВМ и изучение терминала

**Цель:** Подготовить рабочую среду и определить используемую командную оболочку.

1. В Proxmox создайте полный клон шаблона `students-ubuntu26.04-template` с именем `oaks-practicheskaya-rabota-1`.
2. Запустите ВМ, откройте консоль и войдите как `user` с паролем `P@ssw0rd`.
3. Выведите путь к текущей командной оболочке с помощью `echo $SHELL`.
4. Определите текущий терминал командой `tty`.
5. Просмотрите версию Bash командой `bash --version`.
6. Просмотрите список доступных оболочек командой `cat /etc/shells`.
7. Создайте рабочий каталог `/home/user/pr1` и перейдите в него.
8. Убедитесь командой `pwd`, что находитесь в `/home/user/pr1`.

**В отчёт:** скриншот имени ВМ в Proxmox, результаты команд из пунктов 3–6 и `pwd`. Объясните разницу между терминалом и shell.

## Задание 2. Навигация по файловой системе Linux

**Цель:** Научиться перемещаться между каталогами по абсолютным и относительным путям.

1. Перейдите в `/etc` по абсолютному пути и выведите текущий путь.
2. Выведите подробный список файлов `/etc`, включая скрытые, командой `ls -la`.
3. Перейдите в `/var/log` и выведите список файлов с удобным отображением размеров командой `ls -lh`.
4. Из `/var/log` перейдите в соседний каталог `/var/lib` **относительным** путём `../lib`. Проверьте путь.
5. Перейдите в домашний каталог через `cd ~`.
6. Вернитесь в предыдущий каталог командой `cd -` и проверьте результат.
7. Вернитесь в рабочий каталог `/home/user/pr1`.

**В отчёт:** результаты `pwd` в пунктах 1, 4 и 6, примеры `ls -la` и `ls -lh`. Объясните разницу абсолютного и относительного пути, назначение `~` и `..`.

## Задание 3. Создание, копирование, перемещение и удаление файлов

**Цель:** Освоить основные операции с файлами и каталогами.

1. В `/home/user/pr1` создайте структуру `project/src`, `project/docs`, `project/tests` одной командой `mkdir -p`.
2. В каталоге `project/src` создайте пустые файлы `app.txt` и `config.txt` командой `touch`.
3. Скопируйте `config.txt` в `project/docs` с именем `config_backup.txt`.
4. Переименуйте `project/src/app.txt` в `main.txt` командой `mv`.
5. Создайте копию всего каталога `project` с именем `project_copy` с помощью `cp -r`.
6. Создайте пустой каталог `empty_dir`, затем удалите его командой `rmdir`.
7. Удалите файл `project/docs/config_backup.txt` командой `rm`.
8. Проверьте содержимое `project/src`, `project/docs` и `project_copy` с помощью `ls -la`.

**В отчёт:** команды и итоговые списки каталогов. Объясните разницу между `cp`, `mv`, `rm` и `rmdir`.

## Задание 4. Редактирование и просмотр текстовых файлов

**Цель:** Научиться редактировать файлы в `nano` и просматривать текст различными командами.

1. Создайте в `/home/user/pr1/project/docs` файл `notes.txt` с помощью `nano`.
2. Введите **ровно следующие восемь строк**, каждая на отдельной строке:

   ```text
   Linux terminal
   Ubuntu Server
   ERROR disk
   INFO startup
   WARN memory
   ERROR network
   DEBUG test
   INFO finished
   ```

3. Сохраните файл и выйдите из `nano`.
4. Выведите содержимое файла командой `cat`.
5. Выведите его с номерами строк командой `cat -n`.
6. Выведите первые три строки с помощью `head -n 3`.
7. Выведите последние три строки с помощью `tail -n 3`.
8. Откройте файл в `less` и выйдите клавишей `q`.

**В отчёт:** содержимое `notes.txt`, результаты `cat -n`, `head`, `tail`. Объясните назначение `nano`, `less`, `head` и `tail`.

## Задание 5. Поиск текста с помощью grep

**Цель:** Научиться находить строки в текстовых файлах.

Используйте файл `project/docs/notes.txt` из задания 4.

1. Найдите все строки, содержащие `ERROR`.
2. Подсчитайте количество строк, содержащих `ERROR`, командой `grep -c`.
3. Выведите все строки, **не содержащие** `DEBUG`, командой `grep -v`.
4. Найдите строки с `ERROR` **или** `WARN` с помощью `grep -e`.
5. Найдите слово `INFO` как отдельное слово с помощью `grep -w`.
6. Выполните рекурсивный поиск `ERROR` в каталоге `project` с помощью `grep -r`.

**В отчёт:** команды и результаты всех шести проверок. Укажите количество строк с `ERROR`.

## Задание 6. Права доступа к файлам и каталогам

**Цель:** Научиться читать и изменять права доступа в числовом формате.

1. В `/home/user/pr1` создайте каталог `permissions`.
2. Создайте в нём пустые файлы `private.txt` и `public.txt`.
3. Установите для `private.txt` права `600`, а для `public.txt` — `644`.
4. Создайте внутри `permissions` каталог `secret` и установите для него права `700`.
5. Создайте внутри `permissions` каталог `shared` и установите для него права `755`.
6. Просмотрите права командой `ls -la /home/user/pr1/permissions`.
7. Просмотрите права каталогов `secret` и `shared` командой `ls -ld`.

**В отчёт:** команды установки прав и результаты `ls -la` и `ls -ld`. Расшифруйте `600`, `644`, `700` и `755`, объясните назначение `r`, `w`, `x`.

## Задание 7. Поиск файлов с помощью find

**Цель:** Научиться искать файлы по имени, типу и размеру.

1. В `/home/user/pr1` создайте каталог `search`.
2. Создайте в нём файлы `report.log`, `error.log`, `README.txt` и пустой файл `empty.txt`.
3. Создайте подкаталог `search/archive` и файл `search/archive/old.log`.
4. Найдите все файлы с расширением `.log` внутри `search` командой `find -name`.
5. Найдите все обычные файлы в `search` с помощью `find -type f`.
6. Найдите все каталоги внутри `search` с помощью `find -type d`.
7. Найдите все пустые обычные файлы с помощью `find -type f -size 0`.
8. Найдите `.log`-файлы только на верхнем уровне `search`, используя `-maxdepth 1`.

**В отчёт:** команды и вывод каждого поиска. Объясните разницу между `-type f`, `-type d`, `-name` и `-maxdepth`.

## Задание 8. Создание и распаковка архивов

**Цель:** Освоить создание и просмотр архивов `tar` с gzip и xz.

1. В `/home/user/pr1` создайте каталог `archives`.
2. Создайте архив `project.tar.gz` из каталога `project`, используя `tar -czf`.
3. Просмотрите содержимое архива командой `tar -tzf`.
4. Создайте архив `project.tar.xz` из того же каталога, используя `tar -cJf`.
5. Выведите размеры двух архивов командой `ls -lh`.
6. Создайте каталог `archives/restore`.
7. Распакуйте `project.tar.gz` в `archives/restore` с помощью `tar -xzf ... -C ...`.
8. Проверьте, что в `archives/restore/project/docs` находится файл `notes.txt`.

**В отчёт:** команды создания и распаковки архивов, содержимое архива, размеры двух архивов и результат проверки восстановленного файла. Объясните разницу между архивированием и сжатием.

## Задание 9. Переменные окружения и алиасы

**Цель:** Научиться просматривать и задавать переменные окружения и создавать сокращения команд.

1. Выведите значения переменных `HOME` и `PATH`.
2. Создайте переменную окружения `LAB_NAME` со значением `pr1_linux`, используя `export`.
3. Проверьте её значение командой `printenv LAB_NAME`.
4. Добавьте строку `export LAB_NAME=pr1_linux` в конец файла `~/.bashrc`.
5. Примените изменения командой `source ~/.bashrc` и снова проверьте значение переменной.
6. Создайте временный алиас `cpr1`, выполняющий команду `cd /home/user/pr1`.
7. Просмотрите определение алиаса командой `type cpr1`.
8. Перейдите в `/tmp`, затем выполните `cpr1` и проверьте путь через `pwd`.
9. Удалите алиас с помощью `unalias cpr1`.

**В отчёт:** команды, вывод переменных, проверку алиаса и итоговый `pwd`. Объясните назначение `PATH`, `export`, `.bashrc` и `alias`.

## Задание 10. История команд и итоговая проверка

**Цель:** Научиться работать с историей Bash и проверить результаты практической работы.

1. Выведите историю выполненных команд с помощью `history`.
2. Найдите в истории команды, содержащие `mkdir`, используя конвейер `history | grep "mkdir"`.
3. Выполните `pwd`, затем повторите последнюю команду с помощью `!!`.
4. Используйте сочетание `Ctrl+A`, чтобы перейти в начало вводимой строки, и `Ctrl+E`, чтобы перейти в её конец.
5. Используйте `Ctrl+L` для очистки экрана терминала.
6. Проверьте, что существуют каталоги `project`, `project_copy`, `permissions`, `search`, `archives`.
7. Проверьте наличие файла `archives/restore/project/docs/notes.txt`.

**В отчёт:** результаты `history`, фильтрации истории, повторения команды и итоговой проверки. Объясните назначение `!!` и конвейера `|`.
