## Цель работы

Изучить базовые принципы работы в терминале Linux: различия между консолью, терминалом и shell, навигацию по файловой системе, операции с файлами и директориями, просмотр и поиск содержимого, работу с абсолютными и относительными путями, базовое понимание прав доступа, поиск файлов, архивацию и сжатие, переменные окружения, алиасы, историю команд и горячие клавиши.

## Необходимое ПО и ресурсы

- Proxmox VE (любая актуальная версия).
- 1 виртуальная машина на базе Ubuntu Server 24.04.
- Минимальные ресурсы ВМ: 2 vCPU, 2 GB RAM, 20 GB диска.
- Сетевой интерфейс ВМ подключён к `vmbr0` или другому доступному мосту Proxmox.
- Доступ к ВМ через консоль Proxmox или SSH.
- Утилиты, входящие в стандартную поставку Ubuntu Server 24.04:
    - `bash`;
    - `coreutils` (`ls`, `cp`, `mv`, `rm`, `mkdir`, `touch`, `pwd`, `cat`, `head`, `tail` и т.д.);
    - `findutils` (`find`);
    - `grep`;
    - `less`;
    - `nano`, `vim`;
    - `tar`, `gzip`, `bzip2`, `xz`, `zip`, `unzip`.
- Перед выполнением рекомендуется создать снапшот ВМ в Proxmox.

## Задачи на практическую работу

### Блок A. Проверка окружения и shell

1. Определить текущий shell, TTY, версию bash и список доступных shell в системе.

### Блок B. Структура файловой системы и навигация

2. Изучить ключевые директории FHS: `/`, `/etc`, `/var/log`, `/home`, `/proc`, `/sys`, `/tmp`, `/run`, `/opt`, `/usr/bin`, `/usr/sbin`.
3. Освоить навигацию: `pwd`, `ls -la`, `ls -lh`, `cd` с абсолютными и относительными путями, `cd ~`, `cd -`, автодополнение по TAB.

### Блок C. Операции с файлами и директориями

4. Создать структуру директорий и файлов с помощью `mkdir -p`, `touch`.
5. Выполнить копирование, перемещение, переименование и удаление через `cp`, `cp -r`, `cp -a`, `mv`, `rm`, `rm -rf`, `rmdir`.

### Блок D. Просмотр и поиск содержимого

6. Просмотреть файлы командами `cat`, `cat -n`, `less`, `head`, `tail`, `tail -f`.
7. Создать и отредактировать текстовый файл в `nano`.
8. Выполнить поиск по содержимому с помощью `grep`, `grep -r`, `grep -c`, `grep -v`, `grep -w`, `grep -e`.
9. Проверить фильтрацию лога в реальном времени: `tail -f | grep`.

### Блок E. Пути и права доступа

10. Разобрать абсолютные и относительные пути, специальные обозначения `~`, `.`, `..`, `-`.
11. Посмотреть права доступа через `ls -l` и объяснить числовую запись прав для файлов и директорий.

### Блок F. Поиск файлов

12. Освоить `find`: поиск по имени, типу, времени изменения, размеру, выполнение команд над результатами, ограничение глубины.

### Блок G. Архивы и сжатие

13. Создать архивы `tar` с gzip, bzip2 и xz.
14. Просмотреть и распаковать архивы.
15. Выполнить сжатие и распаковку через `gzip`, `bzip2`, `xz`.
16. Создать и распаковать zip-архив.

### Блок H. Переменные окружения и алиасы

17. Просмотреть переменные окружения, создать временную и постоянную переменную, удалить переменную.
18. Создать, проверить и удалить алиасы.

### Блок I. История команд и горячие клавиши

19. Просмотреть историю, найти команду в истории, повторить команду, очистить историю.
20. Проверить основные горячие клавиши bash.

## Реализация

### Блок A. Проверка окружения и shell

```bash
echo $SHELL
tty
bash --version
cat /etc/shells
```

**Пояснение:**
- `echo $SHELL` показывает текущий shell.
- `tty` показывает текущий терминал или псевдотерминал.
- `bash --version` выводит версию bash.
- `cat /etc/shells` показывает список доступных в системе shell.

### Блок B. Структура файловой системы и навигация

Перейдите в корень и осмотрите основные директории:

```bash
cd /
ls -la
ls -la /etc | head
ls -lh /var/log
ls -la /home
ls -la /proc | head
ls -la /sys | head
ls -la /tmp
ls -la /run
ls -la /opt
ls /usr/bin | head
ls /usr/sbin | head
```

Проверьте навигацию:

```bash
pwd
cd /var/log
pwd
cd ../lib
pwd
cd ~
pwd
cd -
pwd
```
