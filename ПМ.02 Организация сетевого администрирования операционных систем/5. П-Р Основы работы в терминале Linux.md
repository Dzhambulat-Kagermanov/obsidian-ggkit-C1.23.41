## Цель работы

Изучить базовые принципы работы в терминале Linux: различия между консолью, терминалом и shell, навигацию по файловой системе, операции с файлами и директориями, просмотр и поиск содержимого, работу с абсолютными и относительными путями, базовое понимание прав доступа, поиск файлов, архивацию и сжатие, переменные окружения, алиасы, историю команд и горячие клавиши.

## Необходимое ПО и ресурсы

- Proxmox VE (любая актуальная версия).
- 1 виртуальная машина на базе Ubuntu Server 24.04.
- Минимальные ресурсы ВМ: 2 vCPU, 2 GB RAM, 20 GB диска.
- Сетевой интерфейс ВМ подключён к `vmbr0` или другому доступному мосту Proxmox.
- Доступ к ВМ через консоль Proxmox или SSH.
- Утилиты, входящие в стандартную поставку Ubuntu Server 24.04:
    - `bash`;
    - `coreutils` (`ls`, `cp`, `mv`, `rm`, `mkdir`, `touch`, `pwd`, `cat`, `head`, `tail` и т.д.);
    - `findutils` (`find`);
    - `grep`;
    - `less`;
    - `nano`, `vim`;
    - `tar`, `gzip`, `bzip2`, `xz`, `zip`, `unzip`.
- Перед выполнением рекомендуется создать снапшот ВМ в Proxmox.

## Реализация

### Блок A. Проверка окружения и shell

```bash
echo $SHELL
tty
bash --version
cat /etc/shells
```

**Пояснение:**
- `echo $SHELL` показывает текущий shell.
- `tty` показывает текущий терминал или псевдотерминал.
- `bash --version` выводит версию bash.
- `cat /etc/shells` показывает список доступных в системе shell.

### Блок B. Структура файловой системы и навигация

Перейдите в корень и осмотрите основные директории:

```bash
cd /
ls -la
ls -la /etc | head
ls -lh /var/log
ls -la /home
ls -la /proc | head
ls -la /sys | head
ls -la /tmp
ls -la /run
ls -la /opt
ls /usr/bin | head
ls /usr/sbin | head
```

Проверьте навигацию:

```bash
pwd
cd /var/log
pwd
cd ../lib
pwd
cd ~
pwd
cd -
pwd
```

Автодополнение:

```bash
cd /var/log/<TAB>
```

**Пояснение:**

- `/` — корень файловой системы.
- `/etc` — конфигурация системы.
- `/var/log` — логи.
- `/home` — домашние директории пользователей.
- `/proc`, `/sys` — виртуальные файловые системы.
- `/tmp`, `/run` — временные данные.
- `/opt` — стороннее ПО.
- `/usr/bin`, `/usr/sbin` — основные и системные программы.
- `pwd` показывает текущую директорию.
- `cd ~` возвращает в домашнюю директорию.
- `cd -` переходит в предыдущую директорию.

### Блок C. Операции с файлами и директориями

Создайте учебную структуру:

```bash
mkdir -p ~/linux-lab/project/{src,tests,docs}
cd ~/linux-lab
touch project/src/main.c
touch project/tests/test1.sh
```

Скопируйте и переместите файлы:

```bash
cp project/src/main.c project/src/main.c.bak
cp -r project/src project/src_backup
cp -a project/src project/src_archive
mv project/tests/test1.sh project/tests/test1_renamed.sh
```

Создайте и удалите пустую директорию:

```bash
mkdir empty_dir
rmdir empty_dir
```

Удалите файлы и директории:

```bash
rm project/src/main.c.bak
rm -rf project/src_backup
```

**Пояснение:**

- `mkdir -p` создаёт директорию вместе с родительскими.
- `touch` создаёт пустой файл.
- `cp` копирует файл.
- `cp -r` копирует директорию рекурсивно.
- `cp -a` сохраняет атрибуты.
- `mv` перемещает или переименовывает.
- `rmdir` удаляет только пустую директорию.
- `rm -rf` удаляет директорию рекурсивно и без подтверждения. Использовать осторожно.

### Блок D. Просмотр и поиск содержимого

Создайте файл:

```bash
cd ~/linux-lab
nano project/docs/readme.txt
```

Введите несколько строк

```bash
Linux terminal practice
This is a readme file.
It contains examples for cat, head, tail and grep.
ERROR: test error
WARN: test warning
DEBUG: test debug
api_key=secret123
erroring is not the same as error
```

Сохраните: `Ctrl+O`, `Enter`, затем `Ctrl+X`.

Просмотрите файл:

```bash
cat project/docs/readme.txt
cat -n project/docs/readme.txt
less project/docs/readme.txt
head -n 5 project/docs/readme.txt
tail -n 5 project/docs/readme.txt
tail -n +3 project/docs/readme.txt
```

Для выхода из `less` нажмите `q`.

Создайте лог-файл:

```bash
nano app.log
```

Добавьте строки:

```bash
INFO: start
ERROR: connection failed
WARN: low disk space
DEBUG: variable x=1
api_key=secret123
INFO: finish
```

Выполните поиск:

```bash
grep "api_key" app.log
grep -r "api_key" ~/linux-lab/
grep -c "ERROR" app.log
grep -v "DEBUG" app.log
grep -w "error" app.log
grep -e "ERROR" -e "WARN" app.log
```

Фильтрация в реальном времени:

```bash
tail -f app.log | grep --line-buffered "ERROR\|Exception"
```

Остановите `tail -f` через `Ctrl+C`.

**Пояснение:**
- `cat` выводит файл целиком.
- `cat -n` нумерует строки.
- `less` позволяет постранично просматривать файл.
- `head` показывает начало файла.
- `tail` показывает конец файла.
- `tail -f` следит за файлом в реальном времени.
- `grep` ищет строки по шаблону.
- `grep -r` ищет рекурсивно.
- `grep -c` считает совпадения.
- `grep -v` исключает строки.
- `grep -w` ищет целое слово.
- `grep -e` задаёт несколько шаблонов.

### Блок E. Пути и права доступа

Проверьте пути:

```bash
pwd
cd /etc
pwd
cd apt
pwd
cd ../..
pwd
cd ~
pwd
cd -
pwd
```

Посмотрите права:

```bash
ls -l /etc/passwd /etc/shadow /usr/bin/ls /home
```

Пример вывода:

```bash
-rw-r--r-- 1 root root  1234 Jan 1 10:00 /etc/passwd
-rw-r----- 1 root shadow 567 Jan 1 10:00 /etc/shadow
-rwxr-xr-x 1 root root 12345 Jan 1 10:00 /usr/bin/ls
```

**Пояснение:**

- `/etc/passwd` обычно имеет права `644` — `rw-r--r--`.
- `/etc/shadow` обычно имеет права `640` — `rw-r-----`.
- `/usr/bin/ls` обычно имеет права `755` — `rwxr-xr-x`.
- Для директорий:
    - `r` — можно прочитать список имён;
    - `w` — можно создавать, удалять и переименовывать файлы;
    - `x` — можно войти в директорию и обращаться к файлам по имени.

### Блок F. Поиск файлов

Выполните поиск:

```bash
find /var -name "*.log"
find /var -iname "*.log"
find /home -type f
find /home -type d
find /etc -mtime -1
find /etc -mmin -30
find /home -type f -size +100M
find /home -type f -size -1M
find /home -type f -size 0
```

Безопасное удаление старых временных файлов:

```bash
find /tmp -type f -name "*.tmp" -mtime +7 -delete
```

Поиск с выполнением команды:

```bash
find ~/linux-lab -name "*.txt" -exec cp {} /tmp/ \;
```

Ограничение глубины:

```bash
find /var -maxdepth 2 -name "*.log"
find /var -mindepth 3 -name "*.log"
```

**Пояснение:**
- `-name` — поиск по имени с учётом регистра.
- `-iname` — без учёта регистра.
- `-type f` — только файлы.
- `-type d` — только директории.
- `-mtime`, `-mmin`, `-ctime` — поиск по времени.
- `-size` — поиск по размеру.
- `-delete` — удалить найденное.
- `-exec {} \;` — выполнить команду для каждого файла.
- `-maxdepth`, `-mindepth` — ограничение глубины поиска.

### Блок G. Архивы и сжатие

Перейдите в учебную директорию:

```bash
cd ~/linux-lab
```

Создайте архивы:

```bash
tar -czf backup.tar.gz project
tar -cjf backup.tar.bz2 project
tar -cJf backup.tar.xz project
```

Просмотрите содержимое:

```bash
tar -tzf backup.tar.gz
tar -tvf backup.tar.gz
```

Распакуйте:

```bash
mkdir -p /tmp/restore
tar -xzf backup.tar.gz -C /tmp/restore
```

Сжатие отдельными утилитами:

```bash
gzip app.log
gunzip app.log.gz

bzip2 app.log
bunzip2 app.log.bz2

xz -9 app.log
unxz app.log.xz
```

ZIP-архивы:

```bash
zip -r project.zip project
unzip -l project.zip
unzip project.zip -d /tmp/unzip_project
```
